# User Guide

Document user-visible feature flows here with expected outcomes suitable for a
manual check or `bc-webclient-runner`. During Test, execute the applicable flow
and record its result and evidence in the feature's
`specs/features/<id>/validation.md`; this guide is not itself validation proof.
Feature review and human approval evidence belongs separately in
`specs/features/<id>/approvals.md`, bound to full-file SHA-256 values.

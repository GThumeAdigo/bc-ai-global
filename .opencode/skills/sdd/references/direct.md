# Direct changes

Use the request/issue and existing behavior as the contract. Inspect references
and relevant invariants, then implement the minimal fix in the main session.
Run the applicable build/analyzer and existing behavior checks. Perform a focused
self-check for affected callers and unrequested changes. No new feature folder,
mandatory worker, general reviewer, roadmap entry or approval ledger.

If investigation changes the intended behavior or reveals material risk, select
Compact/Critical before extending the work. Apply the common SDD stop rules.
